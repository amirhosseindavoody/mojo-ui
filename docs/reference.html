Glossary

Alpha
A color’s opacity. In straight-alpha RGBA, the RGB channels are stored independently of alpha.
Anti-aliasing
Techniques that reduce visible stair steps, often by giving edge pixels partial coverage.
AoS / SoA
Array of structs keeps a pixel’s channels together. Structure of arrays groups the same channel across pixels.
Cache line
A block of bytes that moves together between cache levels or between cache and main memory.
Clipping
Restricting drawing to an area, such as the overlap between a rectangle and the image.
Compositor
The part of a display system that assembles multiple surfaces into the picture on the screen.
Event loop
The repeated work of handling messages, updating state, and drawing or presenting as needed.
FFI
Foreign function interface. A way for one language to make calls across another language’s binary interface.
Framebuffer
The memory holding pixel colors for an image or frame.
Glyph
A drawable shape from a font. Shaping selects which glyphs to draw and where to place them.
Half-open
A range that includes the start and excludes the end. mojo-ui rectangles exclude the right and bottom edges.
Headless
A program can run without a window or display server.
Hit-testing
Checking what lies at a position, such as whether a pointer is inside a button’s bounds.
Immediate mode
UI built by calls made as you produce each frame. Retained mode keeps a widget tree that can be updated over time.
Pitch
The number of bytes from the start of one image row to the start of the next, including any padding.
Presentation
Handing a finished buffer or image to a window or display system to show on screen.
Rasterization
Turning shapes or glyphs into samples on a pixel grid.
SIMD
Single instruction, multiple data. One instruction operates across multiple data lanes.
Source-over
Painting a foreground over a background so the background shows through the source’s transparent portion.
Texture
An image resource a graphics system can read or draw. A texture upload transfers pixel data into that resource.
Tile
A rectangular piece of an image that can be processed as a unit.
